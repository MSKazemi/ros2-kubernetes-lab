# Licence of the fixtures

Every file under `fixtures/` is **100% synthetic**. It is generated by `../fixture_gen.py` from closed-form sine waves. It contains no real robot log, no recorded person, no camera frame and no third-party data. Camera entries are metadata only.

The fixtures are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (SPDX `CC0-1.0`); the `license` field inside each file says the same. The code in the parent directory is under the repository licence ([Apache-2.0](../../../LICENSE)).

These files are test inputs. They are not a benchmark and not a dataset to train on.
