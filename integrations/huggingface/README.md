# Hugging Face integration planning artifacts (not deployed)

This directory provides a **static educational Space starter** and honest **model/dataset card + immutable artifact-manifest templates** for the ROS 2/Kubernetes RobotOps research program.

- [Static HTML Space starter](spaces/robotops-research-explorer/): self-contained source, ready for local preview and manual, owner-authorized HF Space publication; **no Space is live by virtue of committing this folder**.
- [Dataset card template](templates/DATASET-CARD-TEMPLATE.md): intended for actual, licensed and validated LeRobotDataset v3 data, not a toy JSON manifest.
- [Model card template](templates/MODEL-CARD-TEMPLATE.md): intended for a real, compatible and evaluated model/checkpoint, not a claimed training result.
- [Artifact manifest example](templates/artifact-manifest.example.json): all revisions/results null, explicitly NOT_RUN.

Read [capabilities](../../docs/huggingface-robotops/CAPABILITIES.md) and [publication guide](../../docs/huggingface-robotops/SPACE-PUBLICATION.md), then pick [epic #92](https://github.com/MSKazemi/Vagrant-Kubernetes-ROS2-Deployment/issues/92) or [metadata issue #99](https://github.com/MSKazemi/Vagrant-Kubernetes-ROS2-Deployment/issues/99).

**No API keys, paid Jobs, unauthorized uploads, real robot actions or invented Hugging Face model/dataset/Space links.** Publication requires source license review, pinned revisions, human review and explicit user action.
