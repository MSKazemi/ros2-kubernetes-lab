Four suggested experiments

Action freshness

Compare a task-compatible local policy with verified LeRobot remote inference in simulation. Measure p95 sensor-to-valid-action age, missed deadlines and recovery from disconnection, never only HTTP latency.

Research issue #96

VLA simulator reproducibility

Pin simulator, dataset, policy, processor, action units, seeds and hardware before a controlled rollout. A generic base checkpoint does not prove task success.

Research issue #95

Perception under failure

Investigate text-guided detection and relative-depth estimation from licensed images while injecting network delay, compression and timeouts. New experiment; no measurements here.

HF epic #92

Hardware-free baseline

Write a deterministic ROS 2 mock-policy fixture and reject bad shapes, units and stale actions before expensive or safety-sensitive integrations.
