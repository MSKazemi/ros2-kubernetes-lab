Important compatibility boundary

ROS 2 Foxy is end-of-life, the Vagrant cluster uses historical Kubernetes 1.29 / Weave Net, and modern cross-worker DDS delivery is not established. Do not use this lab to control safety-critical robots. Read the safety notes before running privileged scripts.

Choose an authentic next step

If you have Docker and want the smallest supported check, use the Jazzy image instructions. If you're researching ROS middleware discovery, begin with the DDS architecture guide. For practical proposals, follow the repository's 2026 roadmap and open issues.
