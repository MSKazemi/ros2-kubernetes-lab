03 / GET YOUR HANDS DIRTY

Choose your
first experiment.

Two honest starting points: a tested image-local ROS demonstration, or a historical full-cluster lab requiring substantially more resources.

FOLLOW THE VERIFIED SCOPE

Start with a ROS 2 Jazzy container.

Requires Docker, an amd64-capable host, and internet for image dependencies. Builds an image and checks local talker/listener communication.

Full instructions
terminal / bash
git clone https://github.com/MSKazemi/Vagrant-Kubernetes-ROS2-Deployment.git
cd Vagrant-Kubernetes-ROS2-Deployment

docker build --platform linux/amd64 \
  --file ROS2/Dockerfile --tag ros-jazzy-lab:local .

docker run --rm -i --platform linux/amd64 \
  ros-jazzy-lab:local bash -s < scripts/test-ros2-image.sh
Verification scope: this test exercises talker/listener within a single container. It does not verify Kubernetes, cross-pod discovery, or multi-worker messaging.

Explore the historical three-node lab.

Requires Vagrant, VirtualBox and a powerful host. The legacy setup requests approximately 30 GB of VM RAM and 18 vCPUs; a fresh install is not guaranteed.

Read caveats
terminal / bash
git clone https://github.com/MSKazemi/Vagrant-Kubernetes-ROS2-Deployment.git
cd Vagrant-Kubernetes-ROS2-Deployment

# On your host (historical setup)
vagrant up
vagrant ssh controlplane

# Inside the control-plane VM
kubectl get nodes -o wide
kubectl get pods -A
Legacy warning: Kubernetes 1.29, Weave Net and Foxy manifests are historical. ROS talker/listener is not started automatically by vagrant up.

Read full FAQ
Is this a production-ready robotics platform?+

No. This is an educational/research lab. It is not validated for production deployment, safety-critical robots, or real-time guarantees.

Does ROS 2 Jazzy already work across Kubernetes workers?+

No. The Jazzy image has an automated talker/listener test inside one container. Cross-worker Kubernetes/DDS communication is a separate open verification task.

Can I use it without paying for cloud resources?+

Yes, the historical Vagrant setup is local and does not require a paid cloud account. It does require substantial host resources—roughly 30 GB of allocated VM RAM and 18 vCPUs—and old dependencies may need repair.

Where should I begin as a new contributor?+

Start with the contribution guide and good-first-issue labels. You can contribute documentation, tests, or analysis without running the full Vagrant cluster. Claude Code and Codex instructions are available but optional.
