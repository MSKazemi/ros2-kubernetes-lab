02 / Research questions

Four falsifiable experiments.

01 · Action freshness vs model placement

For a compatible simulator policy, compare local, supported asynchronous, and Kubernetes remote inference with network delays, packet loss and server restarts. Main outcomes: valid action age, deadline misses, task completion and outage recovery.

Design and contribute to issue #96

02 · Detect objects over unreliable links

Use a licensed synthetic or public image fixture and Grounding DINO. Compare prompt-controlled detection, compressed image traffic, cloud turnaround and missed detection deadlines.

Proposed extension; results not measured.

03 · Reproduce a LIBERO policy

Pick one explicitly compatible dataset, model checkpoint, simulator and control mode. Compare per-task success across multiple seeds; record hashes and negative cases. A base model alone is not a benchmark.

Design and contribute to issue #95

04 · How do models fail?

Inject schema mismatch, stale images, GPU exhaustion, and policy-server disconnection in simulation. Independent deterministic validation and safe fallback are required; never send unrestricted remote robot commands.

Read the safety-gate requirements

03 / Start contributing

Three levels, one evidence standard.

Beginner · No GPU

Make a synthetic ROS 2 observation fixture, learn camera/action formats, build a deterministic mock and test invalid units and stale timestamps.

Master’s · Perception & evaluation

Implement an optional pinned detection/depth experiment on redistributable images; report raw latencies, correctness definitions, licensing and processor versions.

Coordinate via epic #92

PhD · Distributed policies

Compare task-compatible remote action-chunk policies, fairness, outages and cost. Reproduce real simulator results, include uncertainty and negative cases.

04 / Responsible claims

Frequently asked questions

Does this page run Hugging Face models?

No. It is a static, readable research guide with an interactive category filter. No weights, inference, provider calls or robot actions are performed.

Can I connect any SmolVLA checkpoint to any ROS 2 robot?

No. Camera views, state and action dimensions, units, ordering, normalization, task semantics, policy processor and embodiment must all be verified; physical actuation is excluded here.

Are the benchmark numbers already published?

No. All proposed experiments remain unmeasured until a real run with raw evidence, pinned artifacts and human review has been accepted. The existing results registry is the evidence source.

Which parts can I try without a GPU?

Documentation, simulated observation/action schemas, deterministic mock policies, static website and data-validation exercises. GPU real-policy evaluation requires a separately approved environment.
