02 / Experiments, not anecdotes

From a question to a reproducible result.

STEP 01 / PLAN

Pre-register the comparison

Define the null hypothesis, task, fixture split, deterministic baseline, model revision, metrics, confidence limits and failure conditions before testing.

STEP 02 / MEASURE

Collect full evidence

Record raw predictions, abstentions, timeouts, run manifests, seeds and licenses. Keep model calls opt-in and never run a paid provider in default CI.

STEP 03 / SHARE

Publish methods and limitations

Require raw data, analysis scripts, independent review and explicit limitations before showing measured outcomes. Negative and inconclusive results count.

Reality check: this repository's original Vagrant/Foxy/Kubernetes 1.29 environment is historical. The Jazzy smoke test demonstrates only image-local communication. Cross-worker DDS, Jev runtime integration and robotics task-success metrics are still unverified. This website is a research invitation, not a safety-certified robotics product.
03 / Result transparency

No invented speedups or accuracy charts.

What will eventually appear?

Per-scenario experiment IDs, a clearly labelled status, comparable baseline/JeV runs, measurable outcomes, uncertainty, reproducibility manifests and links to raw evidence.

Today every listed experiment is planned and every performance value is N/A. Those are intentional, not omitted success stories.

05 / Frequently asked questions

Before you join a study.

Do I need a robot, GPU or paid account?

No for the synthetic casebooks, design exercises and offline rules. Actual accelerated inference, live Jev and any robot/simulator benchmarks require separately documented equipment, licenses and permission.

Does clicking Play call Jev?

No. The walkthrough uses preauthored educational text and client-side highlighting, never hosted inference. Jev's role is optional research only. It is not a motor controller or permission oracle.

How do we submit results?

Start with the experiment registry and evidence issue #88. Include a reproducible manifest, raw outcomes, code and negative cases. Unverified claims will not appear as measured results.

Can this become a thesis or class project?

Yes, the scenarios are designed as research prompts and teaching starting points, but feasibility, novelty, ethics approval, licensing and academic supervision must be established for each proposed project.
